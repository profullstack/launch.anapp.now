# Campaign creatives

Three hero creatives, one per experiment variant. The files currently here are
labelled stand-ins generated by `scripts/make-placeholder-creatives.py` because
the supplied artwork was not on disk when the site was built.

`scripts/gen-creatives.py` (needs `OPENAI_API_KEY` with credits; gpt-image-2, 1536x1024) renders the PRD descriptions as a stopgap; set `width`/`height` in `src/lib/creatives.ts` to 1536x1024 if you use it.

Replace them in place with the exact supplied PNGs (same filenames, 4:3 ideally
1600x1200 or larger). `src/lib/creatives.ts` is the only code that references
them; update `width`/`height` there if the real files have a different aspect.
